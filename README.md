# ZenUI

A modern open-source React UI component library.

## Installation

```sh
npm install @senuj05/zenui
```

## Components

- Avatar
- Badge
- Banner
- Button
- Card
- Checkbox
- Dropdown
- Input
- Menu
- Toggle

## Usage

```tsx
import { Button, Card, Toggle } from '@senuj05/zenui'

export default function App() {
  return (
    <Card>
      <Button variant="primary">Click me</Button>
      <Toggle />
    </Card>
  )
}
```

## Requirements

- React 18+
